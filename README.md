# 数学建模技能

这个仓库用于整理可用于数学建模竞赛和数学建模自动化的 AI Skills、Agent 工作流、脚本流水线与参考资料。

当前整理文档：

- [数学建模自动化 Skills 调研](docs/math-modeling-automation-skills.md)

## 推荐优先级

1. `handsomeZR-netizen/mathmodel-skill`：更适合 Codex/Claude 混合使用，流程工程化程度高。
2. `deafenken/auto-MM`：端到端自动化更强，偏比赛流水线。
3. `RealSeaberry/AutoMCM-Pro`：自动驾驶式数模系统，功能激进，适合实验。
4. `XiaoMaColtAI/math-modeling-skill`：中文建模助手包，算法资源和角色分工较完整。
5. `yushui2022/liuhuan-mathmodel-skills`：Trae Skills 体系，适合借鉴流水线设计。

## 使用原则

这些项目适合作为流程辅助、代码实现、数据处理、图表生成、论文草稿和质量检查工具。正式比赛中仍应由参赛者自行判断模型合理性、数据来源、结果解释和最终提交内容，并遵守对应赛事规则。
